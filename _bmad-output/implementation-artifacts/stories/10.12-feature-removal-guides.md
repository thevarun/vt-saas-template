## User Story

As a **template user (developer)**,
I want **clear instructions for removing either or both chat implementations**,
So that **I can cleanly remove what I don't need**.

---

## Context

This story creates comprehensive removal guides for template users who want to remove either the Dify chat implementation, the Vercel AI SDK chat implementation, or both entirely. Since the template provides both options for flexibility, users should be able to cleanly remove what they don't need without leaving orphaned code, dependencies, or database tables.

**Related Epic Stories:**
- Story 10.1: Renamed chat route to `/chat/dify`
- Story 10.2: Cleaned up Dify chat code
- Story 10.3: Database schema consolidation (`vt_saas`)
- Story 10.4: Vercel AI SDK chat API
- Story 10.5: LangFuse integration
- Story 10.6: Mem0 memory integration
- Story 10.7: Vercel chat UI
- Story 10.8: Conversation management API

**Key Deliverables:**
- Guide for removing Dify chat only
- Guide for removing Vercel AI SDK chat only
- Guide for removing all chat functionality
- Database cleanup instructions
- Dependency cleanup commands
- Verification steps

### Writing Guidelines

1. **Tone:** Clear, cautious, step-by-step
2. **Warnings:** Prominently display data loss warnings
3. **Verification:** Include verification at each major step
4. **Troubleshooting:** Common issues and solutions
5. **Completeness:** Every file, every env var, every table

### Common Pitfalls to Address

1. **Forgetting navigation updates** - Leads to broken links
2. **Missing database cleanup** - Orphaned tables
3. **Incomplete dependency removal** - Bloated package.json
4. **Not verifying build** - Broken imports discovered later
5. **Removing shared dependencies** - Breaking other features

### Verification Commands

Include in each guide:
```bash
# Type checking
npm run check-types

# Linting
npm run lint

# Build verification
npm run build

# Test suite (if applicable)
npm test

# Development server
npm run dev
# Manually verify: No chat links, no errors, other features work
```

### Troubleshooting Section Template

For each guide, include common issues:

1. **Build fails with import errors**
   - Cause: Missed file removal or import statement
   - Solution: Search codebase for imports from deleted paths

2. **TypeScript errors about missing types**
   - Cause: Types from removed packages still referenced
   - Solution: Search for type imports and remove

3. **Database migration fails**
   - Cause: Invalid schema or missing dependencies
   - Solution: Review Schema.ts syntax, ensure Drizzle types correct

4. **Navigation still shows chat links**
   - Cause: Cached build or missed component update
   - Solution: Clear `.next` folder, rebuild
