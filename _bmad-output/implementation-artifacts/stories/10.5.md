## Story

As a template user (developer),
I want all LLM calls traced in LangFuse,
so that I can debug, monitor costs, and analyze chat performance.

   **And** trace includes user ID and conversation ID

2. **Given** the trace data
   **When** I view it in LangFuse
   **Then** I see prompt and completion text
   **And** I see token counts
   **And** I see latency metrics
   **And** I see model used

3. **Given** LangFuse is NOT configured
   **When** I make a chat request
   **Then** chat still works (graceful degradation)
   **And** a warning is logged about missing LangFuse config

4. **Given** the integration
   **When** I review the code
   **Then** LangFuse client is in `src/libs/langfuse/`
   **And** setup instructions are documented in `.env.example`

## Dev Notes

### Architecture Context

LangFuse is an **open-source LLM observability platform** that provides:
- Prompt/completion tracing
- Token usage tracking
- Cost calculation
- Latency monitoring
- User session tracking
- Model comparison

**Integration Strategy:**
- Use `langfuse-vercel` package for automatic Vercel AI SDK integration
- Wrap the OpenAI provider with `observeOpenAI()` wrapper
- Traces are sent asynchronously (non-blocking)
- Graceful degradation if not configured

**Key Design Decisions:**
1. **Optional Feature**: Chat works perfectly without LangFuse
2. **Zero Impact**: Tracing errors don't affect chat responses
3. **Automatic Wrapping**: Uses Vercel AI SDK integration (not manual traces)
4. **Singleton Client**: One LangFuse instance per app lifecycle

### LangFuse Vercel AI SDK Integration

**Automatic Tracing via Provider Wrapper:**

```typescript
import { observeOpenAI } from 'langfuse-vercel';
import { createOpenAI } from '@ai-sdk/openai';

// Wrap the provider creation
const openai = observeOpenAI(createOpenAI({
  apiKey: OPENAI_API_KEY,
}), {
  clientInitParams: {
    publicKey: LANGFUSE_PUBLIC_KEY,
    secretKey: LANGFUSE_SECRET_KEY,
  },
});

// Use normally - tracing happens automatically
const model = openai('gpt-4o-mini');
```

**What Gets Traced Automatically:**
- Input messages (prompts)
- Output text (completions)
- Token usage (prompt + completion + total)
- Latency (request duration)
- Model name
- Error messages

**What We Add Manually:**
- User ID (from Supabase session)
- Conversation ID (from database)
- Custom metadata (optional tags)

### LangFuse Client Implementation

**Singleton Pattern:**

```typescript
// src/libs/langfuse/client.ts
import { Langfuse } from 'langfuse';
import { logger } from '@/libs/Logger';
import { LANGFUSE_CONFIG, isConfigured } from './config';

let langfuseClient: Langfuse | null = null;
let configWarningLogged = false;

export function getLangfuseClient(): Langfuse | null {
  if (!isConfigured()) {
    if (!configWarningLogged) {
      logger.warn('LangFuse not configured - skipping LLM tracing');
      configWarningLogged = true;
    }
    return null;
  }

  if (!langfuseClient) {
    try {
      langfuseClient = new Langfuse({
        publicKey: LANGFUSE_CONFIG.publicKey!,
        secretKey: LANGFUSE_CONFIG.secretKey!,
        baseUrl: LANGFUSE_CONFIG.host,
      });
    } catch (error) {
      logger.error({ error }, 'Failed to initialize LangFuse client');
      return null;
    }
  }

  return langfuseClient;
}

export function isLangfuseConfigured(): boolean {
  return isConfigured();
}
```

**Configuration:**

```typescript
// src/libs/langfuse/config.ts
export type LangfuseConfig = {
  publicKey?: string;
  secretKey?: string;
  host?: string;
};

export const LANGFUSE_CONFIG: LangfuseConfig = {
  publicKey: process.env.LANGFUSE_PUBLIC_KEY,
  secretKey: process.env.LANGFUSE_SECRET_KEY,
  host: process.env.LANGFUSE_HOST || 'https://cloud.langfuse.com',
};

export function isConfigured(): boolean {
  return !!(LANGFUSE_CONFIG.publicKey && LANGFUSE_CONFIG.secretKey);
}
```

### Integration with Vercel AI SDK

**Update `src/libs/vercel-ai/client.ts`:**

```typescript
import { observeOpenAI } from 'langfuse-vercel';
import { createOpenAI } from '@ai-sdk/openai';
import type { LanguageModel } from 'ai';
import { isConfigured, VERCEL_AI_CONFIG } from './config';
import { getLangfuseClient, isLangfuseConfigured } from '@/libs/langfuse/client';
import { LANGFUSE_CONFIG } from '@/libs/langfuse/config';

export async function createAIProvider(): Promise<LanguageModel> {
  const { provider, model, openaiApiKey } = VERCEL_AI_CONFIG;

  if (!isConfigured()) {
    throw new Error(`AI provider "${provider}" is not configured.`);
  }

  if (provider === 'openai') {
    let openaiProvider = createOpenAI({ apiKey: openaiApiKey });

    // Wrap with LangFuse if configured
    if (isLangfuseConfigured()) {
      try {
        openaiProvider = observeOpenAI(openaiProvider, {
          clientInitParams: {
            publicKey: LANGFUSE_CONFIG.publicKey!,
            secretKey: LANGFUSE_CONFIG.secretKey!,
            baseUrl: LANGFUSE_CONFIG.host,
          },
        });
      } catch (error) {
        // Log but don't crash - chat should work without tracing
        logger.error({ error }, 'Failed to apply LangFuse wrapper to OpenAI provider');
      }
    }

    return openaiProvider(model);
  }

  // Anthropic and other providers...
}
```

**Note:** The `observeOpenAI` wrapper automatically captures:
- All `streamText` calls
- Input/output tokens
- Latency timing
- Model metadata

### Error Handling

**Graceful Degradation Pattern:**

1. Check if configured BEFORE wrapping provider
2. Log warning ONCE per app lifecycle
3. Continue without tracing if not configured
4. Catch errors during wrapper application
5. Log errors to Sentry (don't throw)
6. Ensure chat API response is never blocked

**Error Scenarios:**

| Scenario | Handling |
|----------|----------|
| Missing API keys | Skip wrapper, log warning, chat works |
| Invalid API keys | Catch error, log to Sentry, chat works |
| LangFuse API down | Tracing fails silently, chat works |
| Network timeout | Async trace fails, chat works |

**Implementation:**

```typescript
if (isLangfuseConfigured()) {
  try {
    openaiProvider = observeOpenAI(openaiProvider, { ... });
  } catch (error) {
    // Don't throw - just log and continue
    logger.error({ error }, 'LangFuse wrapper failed');
    Sentry.captureException(error);
    // openaiProvider remains unwrapped
  }
}
```
