## Technical Specification

### Route Location

```
src/app/[locale]/(unauth)/changelog/page.tsx
```

This is a public page, no authentication required.

### File Reading Strategy

The page reads from `docs/CHANGELOG.md` (generated by semantic-release on releases to main).

**Empty State Handling:**
- If `CHANGELOG.md` does not exist yet, display "No releases yet" message
- Show helpful text: "Releases will appear here once the first version is published to main."

## Implementation Guidelines

### Dependencies

**Install markdown parser:**
```bash
npm install react-markdown remark-gfm
```

**Types:**
```bash
npm install --save-dev @types/react-markdown
```

### Content Reading

```typescript
import fs from 'fs/promises'
import path from 'path'

async function getChangelogContent(): Promise<string | null> {
  try {
    const changelogPath = path.join(process.cwd(), 'docs', 'CHANGELOG.md')
    const content = await fs.readFile(changelogPath, 'utf-8')
    return content
  } catch {
    // File doesn't exist yet
    return null
  }
}
```

### Layout Structure

```tsx
<main className="container mx-auto max-w-4xl px-4 py-12">
  <header className="mb-8">
    <h1 className="text-4xl font-bold text-foreground">Changelog</h1>
    <p className="mt-2 text-muted-foreground">
      Product updates and release notes
    </p>
  </header>

  {content ? (
    <article className="prose prose-neutral dark:prose-invert max-w-none">
      <ReactMarkdown remarkPlugins={[remarkGfm]}>
        {content}
      </ReactMarkdown>
    </article>
  ) : (
    <div className="rounded-lg border border-border bg-muted p-8 text-center">
      <h2 className="text-xl font-semibold text-foreground">No releases yet</h2>
      <p className="mt-2 text-muted-foreground">
        Releases will appear here once the first version is published to main.
      </p>
    </div>
  )}
</main>
```

### Styling Considerations

**Prose styling:**
- Use Tailwind Typography plugin (already installed as `@tailwindcss/typography`)
- Apply `prose` classes for automatic markdown styling
- Use `dark:prose-invert` for dark mode support
- Set `max-w-none` to prevent prose from constraining width

**Semantic colors:**
- `text-foreground` for headings
- `text-muted-foreground` for descriptions
- `bg-muted` for empty state background
- `border-border` for empty state border

### Code Style Requirements

- Server component (no `'use client'` directive needed)
- Use async/await for file reading
- Use `cn()` from `@/utils/Helpers` if needed for className merging
- No semicolons, single quotes for JSX (Antfu ESLint config)
- Proper error handling for missing file

## Notes for Developer

This is a simple content page with minimal complexity. The main considerations are:

1. **Graceful empty state** - CHANGELOG.md won't exist until first release to main
2. **Markdown rendering** - Use react-markdown for safe, styled rendering
3. **SEO** - Proper metadata for search engines
4. **i18n** - Translatable UI strings (though changelog content itself is English)

The page should be fast and lightweight. No client-side JavaScript needed since this is purely content rendering.
