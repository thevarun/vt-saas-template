# Story 10.7: Vercel Chat UI

Status: ready-for-dev

## Story

As a template user (developer),
I want a chat interface at `/chat/vercel`,
so that I can interact with the Vercel AI SDK chat and see my conversation history.

## Acceptance Criteria

1. **Given** an authenticated user
   **When** I navigate to `/chat/vercel`
   **Then** I see a conversation list sidebar (left)
   **And** I see a chat message area (right)
   **And** I can start a new conversation

2. **Given** an existing conversation
   **When** I click on it in the sidebar
   **Then** the URL updates to `/chat/vercel/[conversationId]`
   **And** messages load in the chat area
   **And** I can continue the conversation

3. **Given** a direct URL to a conversation
   **When** I navigate to `/chat/vercel/[conversationId]`
   **Then** that conversation loads directly
   **And** the sidebar shows it as selected

4. **Given** the streaming response
   **When** the AI responds
   **Then** text appears incrementally (streaming effect)
   **And** typing indicator shows during generation

5. **Given** the conversation list
   **When** I have multiple conversations
   **Then** they are sorted by last updated
   **And** I see title and preview text
   **And** I can archive conversations

6. **Given** an unauthenticated user
   **When** they try to access `/chat/vercel`
   **Then** they are redirected to sign-in

### UX Design References

This story uses a **Direct Component Mapping** approach - no visual prototypes needed because we're reusing existing `@assistant-ui/react` components with a different runtime adapter.

**CRITICAL: REUSE EXISTING COMPONENTS**

The Vercel chat UI should look **identical** to the Dify chat. The only differences are:
- Route: `/chat/vercel` instead of `/chat/dify`
- Backend: Vercel AI SDK instead of Dify API
- Runtime adapter: `useVercelUseChatRuntime` instead of `useLocalRuntime`

### Key Implementation Patterns

#### 1. VercelChatInterface Pattern

```typescript
'use client';

import { useChat } from 'ai/react';
import { useVercelUseChatRuntime } from '@assistant-ui/react-ai-sdk';
import { AssistantRuntimeProvider } from '@assistant-ui/react';
import { Thread } from '../Thread';

type VercelChatInterfaceProps = {
  conversationId?: string;
};

export function VercelChatInterface({ conversationId }: VercelChatInterfaceProps) {
  const chat = useChat({
    api: '/api/chat/vercel',
    id: conversationId,
    body: { conversationId },
  });

  const runtime = useVercelUseChatRuntime(chat);

  return (
    <AssistantRuntimeProvider runtime={runtime}>
      <div className="flex min-h-0 flex-1 flex-col overflow-hidden">
        <Thread className="min-h-0 flex-1" />
      </div>
    </AssistantRuntimeProvider>
  );
}
```

**Key Differences from Dify:**
- Uses `useChat` hook instead of custom fetch
- Uses `useVercelUseChatRuntime` instead of `useLocalRuntime`
- No custom SSE parsing (handled by Vercel AI SDK)
- Simpler error handling (built into useChat)
- No custom adapter needed (built-in)

#### 2. ConversationListSidebar Pattern

**Adapt from ThreadListSidebar:**
1. Change API endpoint: `/api/threads` → `/api/chat/vercel/conversations`
2. Change route: `/chat/dify/[threadId]` → `/chat/vercel/[conversationId]`
3. Change type: `Thread` → `Conversation`
4. Change archive endpoint: `/api/threads/[id]/archive` → `/api/chat/vercel/conversations/[id]`
5. Keep all other logic (loading, error, empty states, collapse toggle)

#### 3. Route Page Pattern

```typescript
// src/app/[locale]/(auth)/chat/vercel/page.tsx
import { AppShell } from '@/components/chat/AppShell';
import { VercelChatInterface } from '@/components/chat/vercel/VercelChatInterface';
import { ConversationListSidebar } from '@/components/chat/vercel/ConversationListSidebar';
import { TitleBar } from '@/features/dashboard/TitleBar';
import { getTranslations } from 'next-intl/server';

export async function generateMetadata(props: { params: Promise<{ locale: string }> }) {
  const { locale } = await props.params;
  const t = await getTranslations({ locale, namespace: 'Chat' });

  return {
    title: t('vercel_meta_title'),
    description: t('vercel_meta_description'),
  };
}

export default async function VercelChatPage() {
  const t = await getTranslations('Chat');

  return (
    <div className="flex h-full flex-col gap-6">
      <TitleBar
        title={t('vercel_title')}
        description={t('vercel_description')}
      />

      <div className="min-h-0 flex-1">
        <AppShell sidebar={<ConversationListSidebar />}>
          <VercelChatInterface />
        </AppShell>
      </div>
    </div>
  );
}

export const dynamic = 'force-dynamic';
```

### Error Handling

**Error Boundary Pattern:**
```typescript
import { ErrorBoundary, CardErrorFallback } from '@/components/errors';

export function VercelChatInterface(props: VercelChatInterfaceProps) {
  return (
    <ErrorBoundary
      fallback={(error, reset) => (
        <CardErrorFallback
          error={error}
          onReset={reset}
          message="Chat interface encountered an error"
        />
      )}
      onError={(error) => {
        console.error('[VercelChatInterface] Error:', error);
      }}
    >
      <VercelChatInterfaceInner {...props} />
    </ErrorBoundary>
  );
}
```

**API Error Handling:**
- `useChat` hook handles errors automatically
- Display errors in UI via `chat.error` state
- Add toast notifications for user feedback
- Log errors to Sentry via error boundary
